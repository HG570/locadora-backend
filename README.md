
# Back-end Locadora de Veículos

Este projeto foi desenvolvido por Rafael Pinheiro e faz parte de uma prova realizada entre o dia 01/04/2025 e 02/04/2025 da matéria de Computação em Nuvem I (ISW034) ministrada pelo professor Eduardo Tadeu de Almeida na Fatec de Cotia.


## Instalação

Faça a instalação de dependências do meu projeto

```bash
  npm install
```

Em seguida inicie com:
```bash
  npx ts-node --files src/index.ts
```

Após executar o comando, o projeto estará rodando em:
```bash
  http://localhost:3000/
```
